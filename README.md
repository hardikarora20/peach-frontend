# Peach Frontend

Modern React frontend for the Peach dating app.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

Set `VITE_API_BASE_URL` to your backend URL.

## Features

- Login / register
- Profile creation and edit
- Swipe feed
- Matches list
- Chat screen
- Token persistence
- Protected routes
- Responsive modern UI
